## 6. Edge Cases & Error Handling

- `recipients`: trim + lowercase + dedupe; `EmailStr` validation; cap 20 → 422 (or clamp —

- `last_run_at` is worker-owned; the API must never write it (exclude from schemas).
- `created_by_user_id` set from the acting user on create; not updatable via PATCH.
