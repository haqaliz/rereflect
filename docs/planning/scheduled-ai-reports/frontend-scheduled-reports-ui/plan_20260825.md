## 6. Edge Cases & Error Handling

- `useSearchParams` not used → no Suspense wrapper needed.
- Recipients input: empty → allow (in-app only); invalid emails → client-side toast, and
  rely on backend 422 otherwise.
- Last run display: `formatDate(last_run_at)`; `—` when null.
- Cadence switch: clearing day fields when switching cadence in the dialog (reset on change).
