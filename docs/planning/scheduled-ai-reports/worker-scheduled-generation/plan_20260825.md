## 6. Edge Cases & Error Handling

- **Never a bare `except` around imports** (worker CLAUDE.md — treat as defect on sight).
- `db.rollback()` in every per-schedule except (PendingRollbackError cascade).
- Claim semantics: a crashed window is skipped, not backfilled (PRD §6.3).
- `date_range_days` on the schedule drives `Report.date_range_days` and the report window.
- Narrative failure must not roll back the committed Report — generate narrative BEFORE
  committing the Report row (or in the same transaction guarded by try/except).
