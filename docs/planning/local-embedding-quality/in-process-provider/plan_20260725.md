**Feature:** local-embedding-quality (M5.4) · **Aspect:** `in-process-provider`

**Execution:** strict TDD, one task per phase, branch kept green.

## 0. Summary & decisions

Add a genuinely in-process, CPU, air-gappable embedding provider `local` (sentence-transformers),
strictly opt-in, plugged into the existing provider abstraction. Byte-stable: no install that doesn't
select `local` changes behaviour.

Decisions:
- **Model default:** `LocalEmbeddingProvider.DEFAULT_MODEL = "BAAI/bge-small-en-v1.5"` (384-dim, CPU,
  strong for its size — PRD preferred). The eval (Aspect 3) validates it beats baseline; if it fails
  the gate, revisit the constant then. `all-MiniLM-L6-v2` is the documented lighter fallback.
- **Anti-drift:** the three default sites all reference `LocalEmbeddingProvider.DEFAULT_MODEL` via lazy
  import (`defaults.py::default_model_for_provider`, `factory.py`, `ai_settings._default_embedding_model`)
  — do NOT duplicate the literal. (See memory `embedding-model-defaults-hand-synced`; this makes `local`
  drift-proof, unlike ollama's bare literal.)
- **Load pattern:** mirror M5.1's `transformer.py` — module-level singleton dict keyed by model id +
  `threading.Lock` + double-checked locking; heavy imports (`sentence_transformers`, `torch`) happen
  INSIDE the loader, never at module import.
- **Offline:** the provider honours `HF_HOME` (HF default) and, when `HF_HUB_OFFLINE=1`/
  `TRANSFORMERS_OFFLINE=1` are set, passes `local_files_only=True` to `SentenceTransformer(...)`. (The
  Dockerfile ARG pre-bake is Aspect 4; the provider just respects the env.)
- **Keyless & base_url-less:** add `local` to resolver `_LOCAL_PROVIDERS` (keyless path) but NOT to
  `ai_settings.LOCAL_PROVIDERS` (that set drives the base_url requirement). `local` passes
  `api_key=None, base_url=None` to the factory.

## 2. Tasks (each = one TDD unit)

### Task 1 — `LocalEmbeddingProvider` class + dependency
- **Files:** NEW `src/services/embeddings/providers/local.py`; MODIFY `requirements.txt`.
- **Implement:** `LocalEmbeddingProvider(EmbeddingProvider)` with `DEFAULT_MODEL = "BAAI/bge-small-en-v1.5"`.
  - `__init__(self, model: str | None = None)`: store `self._model = model or DEFAULT_MODEL`,
    `self._dimension: int | None = None`. NO model load in `__init__`.
  - Module-level `_singleton_lock = threading.Lock()` + `_loaded_models: dict[str, "SentenceTransformer"] = {}`;
    a `_get_model(model_id)` double-checked-locking loader that lazily `from sentence_transformers import
    SentenceTransformer`, computes `local_files_only = os.getenv("HF_HUB_OFFLINE")==... or TRANSFORMERS_OFFLINE`,
    builds `SentenceTransformer(model_id, device="cpu", local_files_only=<bool>)`, caches by id, returns it.
  - `embed(self, text) -> list[float]`: `model = _get_model(self._model)`; `vec =
    model.encode(text or "", normalize_embeddings=False)`; convert to `list[float]` (`vec.tolist()` if
    numpy); set `self._dimension = len(result)`; return it.
  - `dimension` property: `self._dimension if not None else 0` (model-derived, never hardcoded).
- **Tests** (`tests/embeddings/test_local_provider.py`): mock `sentence_transformers.SentenceTransformer`
  (patch so `.encode` returns a small numpy/list vector) — assert `embed` returns `list[float]`,
  `dimension == len(vec)`, `__init__` does not load, and offline env → `local_files_only=True` passed to
  the constructor. Add ONE real-model smoke test decorated to **skip when the model can't be loaded**
  (offline/no weights) so CI without network stays green. RED before GREEN.
- **Validation:** `./venv/bin/pytest tests/embeddings/test_local_provider.py -v` (after installing the dep).
- **Commit:** `feat(local-embedding-quality): in-process sentence-transformers local embedding provider`

### Task 3 — Startup pre-warm + async-safety guarantees

- **Validation:** `./venv/bin/pytest tests/ -k "main or lifespan or startup or copilot" -v`.
- **Commit:** `feat(local-embedding-quality): pre-warm local embedding model at startup`

## 3. Testing strategy
- Unit: mock `SentenceTransformer` for deterministic, offline, fast tests; one skip-guarded real smoke.
- Integration (light): resolver→factory→provider produces a working embedder for a `local` org.
- Scope every run (`-k`); never the bare full suite (pre-existing `test_report_ws.py` segfault).

## 4. Edge cases & errors
- ST lib absent: `_embedding_local_deps_available()` False → PATCH 422; factory `create("local")` would
  raise at import inside the branch — acceptable (only reached if config already set); the resolver wraps
  all creation in try/except → returns None (degrade), so a mis-provisioned local org degrades cleanly.
- Offline with no pre-baked weights: `SentenceTransformer(..., local_files_only=True)` raises; resolver
  degrades to None (copilot falls back to LLM path / no match). Document in Aspect 4.
- `model.encode` returning a 2-D array for a single string: ensure we index/normalize to a 1-D
  `list[float]` (test this).
- Thread-safety: concurrent first-calls serialized by the lock; cache keyed by model id.
