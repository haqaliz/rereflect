## 0. Summary & key design decision

Today the template matcher's cross-space skip-filter keys on `(embedding_provider,
embedding_dimension)` only. A model change under the same provider+dimension silently compares old and
new vectors in incompatible spaces. This aspect adds **`embedding_model`** to the stored mapping key
and the skip-filter, and makes system-template reseeding model-aware.

**Key design decision — thread the effective model through `ResolvedEmbedder`:**
The matcher and saver must know the *effective* embedding model string. `ResolvedEmbedder` currently
is `(provider, embedder, dimension_hint)` (`src/services/embeddings/resolver.py`). We add a
`model: Optional[str]` field, set by the resolver to the **effective model** =
`config.model_embeddings` or the provider's default. Consumers read `embedder.model`.

- The model NAME is always known up front (from config or the provider default), even for local
  providers whose *dimension* is only known after the first `embed()`. So keying on model is safe.
- A tiny pure helper `default_model_for_provider(provider)` is added **inside the embeddings package**
  (do NOT import `ai_settings._default_embedding_model` — that's a route module). `ai_settings.py`'s
  existing `_default_embedding_model` stays; optionally it can delegate to the new helper later (not
  required for this aspect).

**Scope guard:** No new model is introduced here (Aspect 2). No default changes. The no-opt-in path
(unchanged provider+model) must stay byte-identical.

## 2. Implementation phases (each = one TDD task)

### Phase 1 — `ResolvedEmbedder.model` + `default_model_for_provider` helper
- **Goal:** make the effective model available to consumers.
- **Files:**
  - `src/services/embeddings/resolver.py` — add `model: Optional[str] = None` to the `ResolvedEmbedder`
    dataclass; in `resolve_embedding_provider`, compute `effective_model = model or
    default_model_for_provider(provider)` (where `model` is the already-read
    `getattr(config, "model_embeddings", None)`) and pass it into `ResolvedEmbedder(...)`.
  - `src/services/embeddings/__init__.py` — export the new helper if placed in a new module, or
    add `src/services/embeddings/defaults.py` with `default_model_for_provider(provider: str) -> Optional[str]`
    returning `text-embedding-3-small` (openai), `models/text-embedding-004` (google),
    `nomic-embed-text` (ollama), `None` (openai_compatible/anything else). Mirror the values in
    `ai_settings._default_embedding_model` exactly (do not change that function in this aspect).
- **RED test (`tests/…/test_embedding_resolver_model.py`):**
  1. resolver returns `ResolvedEmbedder.model == config.model_embeddings` when set;
  2. returns the provider default when `model_embeddings` is NULL;
  3. `default_model_for_provider` returns the exact expected strings per provider.
- **Validation:** `pytest tests/ -k embedding_resolver -v`.
- **Commit:** `feat(local-embedding-quality): thread effective embedding model through ResolvedEmbedder`

### Phase 2 — Migration: add `embedding_model` + model-aware index
- **Goal:** stored rows carry the model; index covers it.
- **Files:** new `alembic/versions/<rev>_add_embedding_model_to_mappings.py` (mirror the structure of
  `y4z5a6b7c8d9_add_embedding_provider_dim_to_mappings.py`).
  - `upgrade()`:
    1. `op.add_column('query_template_mappings', sa.Column('embedding_model', sa.String(100), nullable=True))`.
    2. Backfill: `UPDATE query_template_mappings SET embedding_model = 'text-embedding-3-small'
       WHERE embedding_provider = 'openai' AND embedding_dimension = 1536` (these were written by the
       old OpenAI-only default path — preserves matching for openai installs). All other rows keep
       `embedding_model = NULL` (stale).
    3. `op.drop_index('ix_mappings_provider_dim', table_name='query_template_mappings')` then
       `op.create_index('ix_mappings_provider_dim_model', 'query_template_mappings',
       ['embedding_provider', 'embedding_dimension', 'embedding_model'])`.
  - `downgrade()`: drop the new index, recreate `ix_mappings_provider_dim` on
    `(embedding_provider, embedding_dimension)`, drop `embedding_model`.
  - `down_revision` = the CURRENT live head — obtain via `alembic heads`/`alembic current`, do not grep.
- **Model file:** `src/models/query_template_mapping.py` — add
  `embedding_model = Column(String(100), nullable=True)` (comment: NULL = stale/pre-migration) and
  update `__table_args__` index to `ix_mappings_provider_dim_model` over the three columns.
- **RED test:** an Alembic migration round-trip test (`upgrade` then `downgrade -1`) on a temp
  SQLite/Postgres test DB asserting the column exists after upgrade and is gone after downgrade; and a
  backfill test: a pre-seeded `('openai',1536)` row gets `embedding_model='text-embedding-3-small'`, a
  NULL-provider row stays NULL.
- **Validation:** `alembic upgrade head` succeeds; `alembic heads` still shows a SINGLE head;
  `pytest tests/ -k migration -v`.
- **Commit:** `feat(local-embedding-quality): migration adds embedding_model to query_template_mappings`

### Phase 3 — Saver writes `embedding_model`
- **Goal:** every new mapping stores the model.
- **Files:** `src/services/copilot/template_saver.py`:
  - `_create_mapping(..., provider=None, model=None)` — add `model` param; set
    `embedding_model=model` in both the ORM path and the raw-SQL fallback INSERT (add the column +
    bind param).
  - `save_template` (~L414) and `seed_system_templates` (~L528) — pass `model=embedder.model` into
    `_create_mapping`.
  - `_find_template_by_sql_with_mapping(..., provider=None, model=None)` — extend the idempotency
    filter to also match `embedding_model=model` (ORM `.filter_by(..., embedding_model=model)` and the
    mock fallback loop), so a model change makes `seed_system_templates` re-embed instead of skipping.
  - `seed_system_templates` — read `active_model = embedder.model`; pass it to both
    `_find_template_by_sql_with_mapping(...)` and `_create_mapping(...)`.
- **RED test (`tests/…/test_template_saver_model.py`):**
  1. `_create_mapping(..., provider='local', model='bge')` persists `embedding_model='bge'`;
  2. `seed_system_templates` with an embedder whose `model` differs from the stored mapping re-embeds
     (creates a new mapping with the new model) and is a no-op when `(provider, model)` are unchanged.
- **Validation:** `pytest tests/ -k template_saver -v`.
- **Commit:** `feat(local-embedding-quality): persist + reseed on embedding_model in template saver`

### Phase 4 — Matcher skip-filter keys on model
- **Goal:** never compare across models.
- **Files:** `src/services/copilot/template_matcher.py` `find_match`:
  - SELECT `embedding_model` in the raw SQL (L172-175).
  - `active_model = embedder.model` (alongside `active_provider`, `active_dim`).
  - Skip-filter (L200): `if stored_provider != active_provider or stored_dim != active_dim or
    stored_model != active_model: continue`. NULL `embedding_model` rows are thus always skipped
    (unless active_model is also None — see edge cases).
- **RED test (`tests/…/test_template_matcher_model.py`):**
  1. two stored rows, same `(provider, dim)`, different `embedding_model` → only the active-model row
     is considered;
  2. NULL-model stored row is skipped when active_model is set;
  3. characterization: same provider+model+dim as today → identical best-match result vs a
     pre-change baseline (guards zero regression).
- **Validation:** `pytest tests/ -k template_matcher -v`.
- **Commit:** `feat(local-embedding-quality): matcher skip-filter includes embedding_model`

## 6. Edge cases & error handling

- **Both NULL:** if `active_model is None` (e.g. `openai_compatible` with no configured model) and a
  stored row also has `embedding_model IS NULL`, the skip-filter would treat them as equal. Decide
  explicitly: treat `None` active_model as "unknown" and **still require provider+dim match** — this
  preserves today's behaviour for `openai_compatible` (which has no default model). Document the choice
  in the matcher docstring and cover with a test. (Aspect 5 may later give ollama a concrete default,
  which tightens this.)
- **Mid-upgrade:** NULL-model rows are skipped, never wrong-space-matched; system templates re-embed on
  next `seed_system_templates` (lifespan). Org-saved rows skip-until-overwrite (accepted per PRD).
- **Raw-SQL fallback path** in `_create_mapping` must include the new column or writes will desync from
  the ORM path — cover both.
- **Multi-tenancy:** unchanged; system templates use org #1 as global config (existing pattern).
