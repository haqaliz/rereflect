## 0. Summary
Make the in-process `bge-small-en-v1.5` embedding model air-gap-capable and lean-by-default, exactly
like the M5.1 sentiment model: a `BAKE_EMBEDDING_MODEL=false` ARG in the **backend** Dockerfile (default
= no network / no weights; `--build-arg ...=true` bakes weights into `HF_HOME` for air-gap), reusing the
existing `HF_HOME=/app/models` + CPU-wheel torch install. Then document it in `SELF_HOSTING.md`, add a
`CHANGELOG.md` entry, and mark **M5.4 COMPLETE** in `AI-TRACKING.md`.

**Worker Dockerfile is NOT touched** — the worker has no embedding consumers (it only bakes sentiment).

- **File:** `services/backend-api/Dockerfile` ONLY.
- Add, right after the existing `ARG BAKE_SENTIMENT_MODEL=false` (~line 15):
  ```dockerfile
  # Off by default: the in-process local embedding provider (M5.4) pull-and-caches on
  # first use. Set to "true" at build time for air-gapped installs that need the weights
  # baked into the image (see the RUN step below).
  ARG BAKE_EMBEDDING_MODEL=false
  ```
- Add a second conditional pre-bake RUN after the existing sentiment bake RUN (~line 55), mirroring its
  exact form (reuse `HF_HOME=/app/models` and the already-installed `sentence-transformers`; do NOT add
  a second HF_HOME or pip install):
  ```dockerfile
  # Optional build-time pre-bake of the local embedding model for air-gapped installs.
  # Off by default (BAKE_EMBEDDING_MODEL=false) to keep the base image lean; the local
  # embedding provider is opt-in per-org and, when enabled without a pre-baked cache,
  # downloads + caches the model into HF_HOME on first use instead (needs runtime network once).
  # TODO(offline-packaging): pin a revision SHA (mirror LocalEmbeddingProvider.DEFAULT_MODEL).
  RUN if [ "$BAKE_EMBEDDING_MODEL" = "true" ]; then \
          python -c "from sentence_transformers import SentenceTransformer; \
  SentenceTransformer('BAAI/bge-small-en-v1.5')" ; \
      fi
  ```

If a docker build is feasible in reasonable time: `docker build --build-arg BAKE_EMBEDDING_MODEL=false -f services/backend-api/Dockerfile ...` succeeds and does NOT bake (no SentenceTransformer download in the layer).
