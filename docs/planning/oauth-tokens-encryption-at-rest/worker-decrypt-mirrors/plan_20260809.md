## The `_decrypt` helper (byte-identical to `src/tasks/zendesk_sync.py:80-89`)

```python
def _decrypt(token: str) -> str:
    """Decrypt a Fernet-encrypted string using LLM_ENCRYPTION_KEY."""
    from cryptography.fernet import Fernet
    key = os.environ.get("LLM_ENCRYPTION_KEY")
    if not key:
        raise ValueError("LLM_ENCRYPTION_KEY is not set")
    return Fernet(key.encode()).decrypt(token.encode()).decode()
```

Add it (module-level, exactly this body) to each of the four files that read the token.
Read-site error contract: wrap in `try/except (ValueError, InvalidToken)` → record the
failure as the file's local error shape (see per-file notes), **never retry** (non-
transient config error — the R6 contract zendesk_sync documents), never raise out of a
Celery task.

### Phase 1: RED — pin decrypt-at-send in tests

**Goal:** failing tests asserting each of the 5 read sites sends the **decrypted** token,
and that missing/corrupt keys produce the error contract.

**Prerequisites:** none (tests reference the helpers that don't exist yet → RED).

**Files to create/modify (test only):**

**Implementation steps (test code only):**
1. For each read site: set up an `Integration`-mirror row with `oauth_access_token = <fernet ciphertext of a known token>` (encrypt in the test with a local `Fernet` + `LLM_ENCRYPTION_KEY` patched to a known key), call the path, and assert the token that reaches the Slack/Intercom API call (`send_slack_message_oauth`, `fetch_context`, `conversations.list`) is the **plaintext** original — not the ciphertext. These are the truthiness-trap regression tests.
2. Missing-key test at one representative site (e.g. `send_slack_alert`): `patch.dict(os.environ, {"LLM_ENCRYPTION_KEY": ""})` → the site returns its error shape (`{"status": "error", "reason": ...}` or a recorded `channel_errors` entry), does NOT raise, does NOT call the API.
3. Corrupt-ciphertext test at the same site: `oauth_access_token = "garbage-not-fernet"` → same error shape, no API call.
4. `test_intercom_sync.py`: the `_decrypt` monkeypatch is removed (the existing tests patch `src.tasks.intercom_sync._decrypt`); add one test that calls `intercom_sync._decrypt` directly with a real Fernet-encrypted token (env patched) and asserts the plaintext round-trips — this is the test that fails today with `ModuleNotFoundError` and pins R4.
5. Run the touched test files — **expect failures (RED)**.

- `intercom_sync._decrypt` must work in the worker's import universe (this is the R4 regression).
