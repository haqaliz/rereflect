     ```python
     import sqlalchemy as sa

         op.add_column(
             'intercom_integrations',
             sa.Column('backlog_remaining', sa.Integer(), nullable=True),
         )


     def downgrade() -> None:
         op.drop_column('intercom_integrations', 'backlog_remaining')
     ```

## 6. Edge cases & error handling

- **Existing rows**: nullable column with no `server_default` — PostgreSQL adds it
  instantly without a rewrite concern; every existing row reads NULL, which is the
  honest pre-run state (no fake 0). This is *why* nullable was chosen over NOT NULL +
  server_default 0 (spec open-question resolution).
- **Downgrade**: drops exactly `backlog_remaining`; the writeback and sync siblings
  survive (pinned by the round-trip test's sibling set).
- **Disconnected / absent row**: `intercom_status` :450 returns
  `IntercomStatusResponse(connected=False)` — the new field falls through to its
  Pydantic default `None`. No code change at :450.
- **OAuth path / never-synced**: the column stays NULL (the OAuth path has no pull
  and the sync task does not run for it) — the response renders `None`, which the
  frontend aspect will treat as "no row".
- **Type drift**: worker mirror must be `Integer` — if someone writes `BigInteger`,
  the type-parity test fails on `_static_cache_key` (Integer vs BigInteger differ).
- **Parity name coverage**: because the tuple now includes `backlog_remaining` and the
  name test compares full column-name sets, a worker-mirror omission is caught by the
  name test, and a type slip by the type test — both without adding new test methods.
- **SQLite vs PG**: nullable Integer has no dialect nuance — `nullable is True`
  asserts identically on both; no boolean-literal gymnastics needed.
- **Alembic heads**: if `down_revision` is wrong or stale, `alembic heads` prints ≥2
  heads and CI fails (:93-97). Pinned to `'e4f5a6b7c8d9'`.
- **Nothing else moves**: no Redis keys, no sync-task behavior, no connect/disconnect
  changes, no plan gate (`SELF_HOSTED=true` — do not add one).
