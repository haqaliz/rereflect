## 6. Edge cases & error handling

- **OAuth callbacks must stay JWT-less** — provider browser redirects carry no
  Authorization header; gating them breaks connect. Exemption is the point, not a
  miss.
- **Plan-gate 403 dict vs role 403 string** — routes with both deps must keep the
  feature-gate dict body when the role dep passes (existing `test_intercom.py:122-134`
  asserts the dict); role dep failure returns the plain-string detail. Order in the
  `dependencies=[...]` list does not change the outcome for the tests in question —
  do not reorder existing `require_feature` entries.
- **`GET /slack/template-variables` contract change** — if any test asserts it is
  public, that test is updated in Phase A (flagged in PRD risk #4); confirm with grep
  `template-variables` in `tests/` before editing.
- **Member-visible 403 surfaces (UI)** — accepted consequence; follow-up chore
  `frontend-integration-role-guards` handles the UI. Not in this branch.
- **Multi-tenancy** — role check is additive on `get_current_org`; org scoping
  unchanged.
- **Helpers frozen** — `send_slack_message` / `send_discord_message` /
  `oauth_states` must keep name/signature/location (external importers + tests patch
  by module path).
