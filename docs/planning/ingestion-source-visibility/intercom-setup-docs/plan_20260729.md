**Style** — mirror `## Connecting Salesforce` (lines 978–1061) for the env-var half and

### Intro (mirror Zendesk's 1330–1348)

Frame Intercom as an **inbound** source. Then a **"Shipped scope for this release"** bullet
list stating plainly:

- **Webhook-only.** Unlike Zendesk, there is **no periodic pull** — if the webhook is not
  wired, nothing arrives. (`IntercomConnector.fetch_new_items` is not implemented; the daily
  02:00 UTC integration sync is a no-op for Intercom.)
- Three conversation topics are handled (listed in step 5).
- One feedback item per conversation event, deduped by conversation/part id.
- **Customer email is not populated** on the feedback item itself — it appears in
  `source_metadata` (`author_email` / `contact_email`), and only when the source's field
  mapping enables author/context enrichment.
- **No write-back.** Rereflect does not add notes to or close Intercom conversations.
- Requires an OAuth app you register yourself; there is no token-paste path (unlike
  Zendesk, Jira and Asana).

### `### 1. Create an Intercom app`

Numbered list: Intercom Developer Hub → new app → note **Client ID** and **Client Secret** →
register the redirect URL, which must exactly equal `INTERCOM_REDIRECT_URI` (next step).
State that permissions are configured on the app in the Developer Hub — Rereflect requests
no scopes in the authorize URL. Name what the app needs to be able to do in plain terms
(read conversations and contacts; send the conversation webhooks in step 5) **without
naming scope strings**.

### `### 2. Configure environment variables`

"Set these in your backend `.env`:" then a `| Variable | Purpose |` table:

| Variable | Purpose |
|----------|---------|
| `INTERCOM_CLIENT_ID` | Intercom app Client ID |
| `INTERCOM_CLIENT_SECRET` | Intercom app Client Secret. **Also the HMAC secret for webhook verification** (step 5) — required, not optional. |
| `INTERCOM_REDIRECT_URI` | Must exactly match the redirect URL registered on the Intercom app. **Defaults to `http://localhost:8000/api/v1/integrations/intercom/oauth/callback` — you must override this for any non-localhost deployment.** |
| `FRONTEND_URL` | Used to build the post-OAuth redirect back to the app |

Close with the Salesforce line verbatim: "Restart the backend after setting these so the
OAuth routes pick them up."

Add a blockquote callout that `INTERCOM_CLIENT_SECRET` must be set before exposing the
webhook endpoint — phrased as a requirement, per D1.

### `### 3. Connect from the app`

**Settings → Integrations → New → Intercom**, click Connect. Note that if
`INTERCOM_CLIENT_ID` is unset the request fails with **HTTP 500 "Intercom OAuth is not
configured"** — call it a configuration error, not a permissions error, so operators don't
chase RBAC.

### `### 4. Create the Intercom feedback source`

**This must happen after step 3** — an Intercom source requires an `integration_id` from the
connected integration, and the API returns **400 "Intercom sources require an
integration_id"** otherwise. The workspace is carried over from the integration
automatically. Mention the trigger choice (new conversations / replies / ratings / all, plus
keyword filters) and `auto_import` vs. the pending-review queue.

### `### 5. Subscribe the Intercom webhook`

Numbered steps: in the Intercom app's webhook settings, point delivery at
`POST <your-api-base>/api/v1/webhooks/intercom/events` and subscribe to exactly:

- `conversation.user.created`
- `conversation.user.replied`
- `conversation.rating.added`

Any other topic is accepted and ignored. Note signing: Intercom signs with the app Client
Secret; Rereflect verifies `X-Hub-Signature` as HMAC-SHA1 over the raw body.

**Bold callout:** this step is not optional — it is the only ingestion path.

### `### Verify`

Two bullets, Zendesk-style: what Settings → Integrations → Intercom shows once connected
(workspace name/id), and what working looks like (a new Intercom conversation appears as
feedback within a minute or two — or in the pending queue if `auto_import` is off).

### Cross-origin callout

Copy the Salesforce blockquote at line 1027 essentially verbatim — the Intercom OAuth
callback binds state the same way and the caveat applies identically.

### `### All features unlocked`

Copy Zendesk's closing boilerplate (1493–1497).
