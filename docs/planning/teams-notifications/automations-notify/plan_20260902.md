- **Goal:** `channels: ["teams"]` on a rule posts one MessageCard per active Teams integration, org-wide, with a `teams_sent` result key.
- **Files:** `services/backend-api/src/services/automation_engine.py`
- **Steps:**
  1. RED: extend the `_execute_notify` tests (find them: `grep -rl "_execute_notify" services/backend-api/tests/`): rule with `channels: ["teams"]` + active Teams integration → sender called once per integration, result `{"notifications_created": 0, "slack_sent": 0, "teams_sent": 1}`, `error: None`; no Teams integration → error string contains `teams: no active Teams integration configured` (mirror :622-623); unknown channel still loud.
  2. `KNOWN_NOTIFY_CHANNELS` (:35): add `"teams"`.
  3. In `_execute_notify` after the slack block (:611-667):
     ```python
     teams_sent = 0
     if "teams" in channels:
         # org-wide, once per rule firing — mirrors the slack block
         integrations = db.query(Integration).filter(
             Integration.organization_id == org_id,
             Integration.type == "teams",
             Integration.is_active.is_(True),
         ).all()
         if not integrations:
             channel_errors.append("teams: no active Teams integration configured")
         title = f"Automation: {rule.name}"
         for integration in integrations:
             try:
                 webhook_url = (integration.config or {}).get("webhook_url")
                 if not webhook_url:
                     channel_errors.append(f"teams: integration {integration.id} has no webhook_url")
                     continue
                 from src.api.routes.integrations import send_teams_message
                 res = send_teams_message(webhook_url=webhook_url, title=title, text=message_template)
                 if res.get("success"):
                     teams_sent += 1
                 else:
                     channel_errors.append(f"teams: integration {integration.id}: {res.get('error')}")
             except Exception as exc:
                 logger.warning("AutomationEngine: teams notify failed for integration %s: %s", integration.id, exc)
                 channel_errors.append(f"teams: integration {integration.id}: {exc}")
     ```
  4. Result dict (:679-683): add `"teams_sent": teams_sent` — **do not rename `slack_sent`** (execution-log rendering + characterization tests depend on it).
  5. GREEN.
- **Validation:** `pytest tests/ -v` (backend)

- Suites: `pytest tests/ -v` in both services.

## 5. Environment & secrets

- None new. Postgres + Redis for the worker suite.

## 6. Edge cases

- Rule declares `channels: ["teams"]` but no integration → **loud** error in the execution result (not silent) — the P1 lesson.
- Integration inactive → not selected.
- Multiple active Teams integrations → one card each, all counted.
- Sender failure → `error` string, `teams_sent` unchanged, status becomes `partial_failure`/`failed` via the existing error-join.
