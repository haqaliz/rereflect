## Edge cases & error handling

- **First-load defaults:** `DEFAULT_PREFERENCES` carries `channel_discord: true`
  for all 8 types — no `undefined` rendering.
- **Absent API field (stale backend):** not a supported state — frontend and
  backend ship atomically; the API sentinel handles the reverse direction.
- **No Discord integration connected:** toggle still renders (parity with
  Slack/Intercom); delivery is a no-op until a webhook exists.
