- **Files:**

    (:45-46); add `_sign_oauth_state`/`_verify_oauth_state` helpers (mirror
    `salesforce_integration.py:252-289`: `_sign_state`/`_verify_state`, app-secret
    keyed HMAC, `STATE_TTL_SECONDS = 600`, fail-closed `None` on any invalid/
    expired/unsafe-compare mismatch). Pin which secret: the Salesforce precedent

    `linear_oauth_states` deleted; authorize (:321) + callback (:360) use the same
    helpers (import from a shared module — put the helpers in a small
    `services/oauth_state.py` used by both routers, or import across the two

- **Files:**

    (a response field the docs + tests reference; PATCH responses may omit it).

    header → 401 (unchanged logic); when the source has NO secret (grandfathered),

    have a secret, so the no-secret branch only exists for grandfathered sources.

    secrets area (:2465-2471 vicinity): the model (capability URL + per-source

  new source with secret + correct header → 200; missing header → 401; wrong →
  401; grandfathered source without secret → accepted (documented posture);
  create response displays the token once; token round-trips to delivery.
- **Commit:** `feat(api): generic webhook sources get a display-once secret, fail closed (TDD)`.
