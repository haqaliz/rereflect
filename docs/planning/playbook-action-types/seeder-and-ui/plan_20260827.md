## 5. Edge Cases & Error Handling

- Pristine seeded row with operator-edited sequence → converged (documented predicate —
  note it in the seeder docstring)
- Cloned/org rows → never touched
- Automation picker empty org → disabled select with "No automations"
- `action_log` missing/empty on an execution → "No actions recorded"
- A `result` that isn't an object (legacy rows) → safe render (`String(result)` fallback)
