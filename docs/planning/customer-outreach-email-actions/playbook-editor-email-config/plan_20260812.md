## 6. Edge Cases & Error Handling

- Unknown template key from an old/cloned playbook → render the raw key with a warning,
  **keep it in config** on save (never blank — see spec Edge cases).
- Templates endpoint failing → `BUILTIN_OUTREACH_TEMPLATES` fallback + `toast.error`;
  saves still serialize the current select values.
- `send_email` step with missing config → defaults render; save writes the resolved
  config.
- Member role → toggle hidden (never rendered, never called).
- `outreach_opt_out` absent from GET profile → `false` initial state (flag the
  outreach-core GET-profile gap to that implementer — spec Open Questions).
- PATCH failure → revert switch + toast; do not leave the UI lying.
- Type-switch away from `send_email` keeps the config dict (backend stores
  free-form JSON, `churn_playbook.py:20-22`; harmless).
