## 6. Edge Cases & Error Handling

- Blank/uppercase emails: normalize `strip().lower()` before token + opt-out lookups.
- Opt-out flag checked in-DB **and** cooldown checked in-Redis at send time (not at
  queue time) — the bulk aspect re-checks here too.
- `OUTREACH_COOLDOWN_HOURS` unparseable → log + fall back to 24.
- Token for an email with no health row: upsert creates the row (AC8).
- Cross-org token → verify fails (token binds org id) → 400.
- Never raise on send failure — always return the dict (callers record it).
